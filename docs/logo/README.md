# amanuense logo

A scribe shaped like a keyhole, writing in a closed room: the mail is read inside, and stays there.
The idea is the repository owner's; the AI agent that wrote amanuense drew it in SVG.

| File | Use |
|---|---|
| `logo.svg`, `logo.png` | icon and name, for light backgrounds (ink-blue name) |
| `logo-dark.svg`, `logo-dark.png` | icon and name, for dark backgrounds (parchment name) |
| `icon.svg`, `icon-512.png` … `icon-32.png` | the icon alone |

Colours: parchment `#f4ead5` to `#e8d9b8`, ink `#1f2c4e`, wax red `#c8463a`.
The name is Fira Mono Medium (SIL Open Font License 1.1), as outlines: no font is needed to show it.
